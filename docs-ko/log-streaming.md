# 로그 스트리밍

/// info | 기능 사용 가능 여부
로그 스트리밍은 엔터프라이즈 자체 호스팅 및 클라우드 요금제에서 사용할 수 있습니다.
///

로그 스트리밍을 사용하면 n8n에서 자신의 로깅 도구로 이벤트를 보낼 수 있습니다. 이를 통해 자신의 알림 및 로깅 프로세스에서 n8n 모니터링을 관리할 수 있습니다.

## 로그 스트리밍 설정

로그 스트리밍을 사용하려면 스트리밍 대상을 추가해야 합니다.

1. **설정** > **로그 스트리밍**으로 이동합니다.
2. **새 대상 추가**를 선택합니다.
3. 대상 유형을 선택합니다. n8n은 **새 이벤트 대상** 모달을 엽니다.
4. **새 이벤트 대상** 모달에서 이벤트 대상에 대한 구성 정보를 입력합니다. 이는 사용 중인 대상 유형에 따라 다릅니다.
5. 스트리밍할 이벤트를 선택하려면 **이벤트**를 선택합니다.
6. **저장**을 선택합니다.

/// note | 자체 호스팅 사용자
If you self-host n8n, you can configure additional log streaming behavior using [Environment variables](/hosting/configuration/environment-variables/logs.md#log-streaming).
///
