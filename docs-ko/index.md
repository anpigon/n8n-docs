# n8n 문서에 오신 것을 환영합니다

## n8n 소개

n8n(엔에잇엔으로 발음)은 코드를 거의 또는 전혀 사용하지 않고도, API가 있는 모든 앱을 다른 앱과 연결하고 데이터를 조작할 수 있도록 도와줍니다.

* **사용자 정의 가능**: 매우 유연한 워크플로우와 사용자 정의 노드를 구축할 수 있는 옵션을 제공합니다.
* **편리함**: npm 또는 Docker를 사용하여 n8n을 사용해 보거나, 인프라 관리를 저희에게 맡기고 싶다면 클라우드 호스팅 옵션을 사용할 수 있습니다.
* **개인정보 보호 중심**: 개인정보 보호 및 보안을 위해 n8n을 직접 호스팅할 수 있습니다.
