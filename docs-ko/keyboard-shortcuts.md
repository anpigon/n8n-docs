# 키보드 단축키 및 제어

n8n은 일부 작업에 대한 키보드 단축키를 제공합니다.

## 워크플로우 제어
 
 - **Ctrl** + **Alt** + **n**: 새 워크플로우 생성
 - **Ctrl** + **o**: 워크플로우 열기
 - **Ctrl** + **s**: 현재 워크플로우 저장 
 - **Ctrl** + **z**: 실행 취소
 - **Ctrl** + **Shift** + **z**: 다시 실행
 - **Ctrl** + **Enter**: 워크플로우 실행

## 캔버스

### 캔버스 이동

 - **Ctrl** + **마우스 왼쪽 버튼** + 드래그: 노드 뷰 이동
 - **Ctrl** + **마우스 가운데 버튼** + 드래그: 노드 뷰 이동
 - **Space** + 드래그: 노드 뷰 이동
 - **마우스 가운데 버튼** + 드래그: 노드 뷰 이동
 - 터치스크린에서 두 손가락: 노드 뷰 이동

### 캔버스 확대/축소

- **+** 또는 **=**: 확대
- **-** 또는 **_**: 축소
- **0**: 확대/축소 수준 재설정
- **1**: 워크플로우에 맞게 확대/축소
- **Ctrl** + **마우스 휠**: 확대/축소

### 캔버스 내 노드

- 노드 **두 번 클릭**: 노드 세부 정보 열기
- 하위 워크플로우 노드 **Ctrl/Cmd** + **두 번 클릭**: 새 탭에서 하위 워크플로우 열기
- **Ctrl** + **a**: 모든 노드 선택
- **Ctrl** + **v**: 노드 붙여넣기
- **Shift** + **s**: 스티커 메모 추가

### 캔버스에서 하나 이상의 노드가 선택된 경우

 - **아래쪽 화살표**: 현재 노드 아래의 형제 노드 선택
 - **왼쪽 화살표**: 현재 노드 왼쪽의 노드 선택
 - **오른쪽 화살표**: 현재 노드 오른쪽의 노드 선택
 - **위쪽 화살표**: 현재 노드 위의 형제 노드 선택
 - **Ctrl** + **c**: 복사
 - **Ctrl** + **x**: 잘라내기
 - **D**: 비활성화
 - **Delete**: 삭제
 - **Enter**: 열기
 - **F2**: 이름 변경
 - **P**: 노드에 데이터 고정. 자세한 내용은 [데이터 고정](/data/data-pinning.md)을 참조하세요.
 - **Shift** + **왼쪽 화살표**: 현재 노드 왼쪽의 모든 노드 선택
 - **Shift** + **오른쪽 화살표**: 현재 노드 오른쪽의 모든 노드 선택
 - 하위 워크플로우 노드 **Ctrl/Cmd** + **Shift** + **o**: 새 탭에서 하위 워크플로우 열기 

## 노드 패널

 - **Tab**: 노드 패널 열기
 - **Enter**: 선택한 노드를 워크플로우에 삽입
 - **Escape**: 노드 패널 닫기

### 노드 패널 카테고리

- **Enter**: 노드를 워크플로우에 삽입, 카테고리 접기/확장, 하위 카테고리 열기
- **오른쪽 화살표**: 카테고리 확장, 하위 카테고리 열기 
- **왼쪽 화살표**: 카테고리 접기, 하위 카테고리 뷰 닫기

## 노드 내

- **=**: 빈 매개변수 입력에서 [표현식](/glossary.md#expression-n8n) 모드로 전환합니다.
