# 아키텍처

n8n의 기본 아키텍처를 이해하는 것은 다음과 같은 경우에 유용합니다.

* n8n 임베딩
* n8n의 기본 데이터베이스 사용자 정의

이 섹션은 현재 작업 중입니다. 질문이 있는 경우 [포럼](https://community.n8n.io/){:target=_blank .external-link}을 통해 문의하고 어떤 아키텍처 문서가 유용할지 n8n에 알려주세요.
