# n8n 확장

많은 수의 사용자, 워크플로우 또는 실행으로 n8n을 대규모로 실행하는 경우 우수한 성능을 보장하기 위해 n8n 구성을 변경해야 합니다.

n8n은 필요에 따라 다른 [모드](/hosting/scaling/queue-mode.md)로 실행할 수 있습니다. `queue` 모드는 최고의 확장성을 제공합니다. 구성 세부 정보는 [큐 모드](/hosting/scaling/queue-mode.md)를 참조하십시오.

데이터베이스 성능을 향상시키기 위해 데이터 저장 및 정리를 구성할 수 있습니다. 자세한 내용은 [실행 데이터](/hosting/scaling/execution-data.md)를 참조하십시오.
