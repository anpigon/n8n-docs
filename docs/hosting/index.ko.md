# n8n 자체 호스팅

이 섹션에서는 엔터프라이즈 및 커뮤니티 자체 호스팅 에디션 모두에 대한 n8n 설정 지침을 제공합니다. 커뮤니티 에디션은 무료이며 엔터프라이즈 에디션은 유료입니다.

사용 가능한 기능 목록은 [커뮤니티 에디션 기능](/hosting/community-edition-features.md)을 참조하세요.

<div class="grid-cards-vertical cards" markdown>

- __설치 및 서버 설정__

	npm 또는 Docker를 사용하여 모든 플랫폼에 n8n을 설치합니다. 또는 인기 있는 호스팅 플랫폼에 대한 가이드를 따르세요.

	[:octicons-arrow-right-24: Docker 설치 가이드](/hosting/installation/docker.md)

- __구성__

	환경 변수로 n8n을 구성하는 방법을 알아보세요.

	[:octicons-arrow-right-24: 환경 변수](/hosting/configuration/environment-variables/index.md)

- __사용자 및 인증__

	 n8n 인스턴스에 대한 사용자 인증을 선택하고 설정합니다.

	[:octicons-arrow-right-24: 인증](/hosting/configuration/user-management-self-hosted.md)

- __확장__

	데이터, 모드 및 프로세스를 관리하여 n8n을 대규모로 원활하게 실행합니다.

	[:octicons-arrow-right-24: 확장](/hosting/scaling/queue-mode.md)

- __n8n 보안__

	SSL, SSO 또는 2FA를 설정하거나 일부 데이터 수집 또는 기능을 차단하거나 옵트아웃하여 n8n 인스턴스를 보호합니다.

	[:octicons-arrow-right-24: n8n 보안 가이드](/hosting/securing/overview.md)

- __스타터 키트__

	n8n 또는 AI를 처음 사용하시나요? 자체 호스팅 AI 스타터 키트를 사용해 보세요. n8n에서 선별한 이 키트는 자체 호스팅 n8n 플랫폼과 호환되는 AI 제품 및 구성 요소를 결합하여 자체 호스팅 AI 워크플로우 구축을 시작하는 데 도움을 줍니다.

	[:octicons-arrow-right-24: 스타터 키트](/hosting/starter-kits/ai-starter-kit.md)

</div>
