# 과거 실행 디버그 및 다시 실행

/// info | 기능 가용성
n8n 클라우드 및 등록된 커뮤니티 플랜에서 사용 가능합니다.
///

이전 실행의 데이터를 현재 워크플로우로 로드할 수 있습니다. 이는 실패한 프로덕션 실행의 데이터를 디버깅하는 데 유용합니다. 실패한 실행을 보고, 워크플로우를 수정하여 수정하고, 이전 실행 데이터로 다시 실행할 수 있습니다.

## 데이터 로드

이전 실행에서 데이터를 로드하려면:

1. 워크플로우에서 **실행** 탭을 선택하여 **실행** 목록을 봅니다.
2. 디버그하려는 실행을 선택합니다. n8n은 워크플로우가 성공했는지 실패했는지에 따라 옵션을 표시합니다.
	* 실패한 실행의 경우: **편집기에서 디버그**를 선택합니다.
	* 성공적인 실행의 경우: **편집기로 복사**를 선택합니다.
3. n8n은 실행 데이터를 현재 워크플로우로 복사하고 워크플로우의 첫 번째 노드에 [데이터를 고정](/data/data-pinning.md)합니다.

/// note | 저장하는 실행 확인
**실행** 목록에서 사용할 수 있는 실행은 [워크플로우 설정](/workflows/settings.md)에 따라 다릅니다.
