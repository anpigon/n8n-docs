# 실행

실행은 워크플로우의 단일 실행입니다.

## 실행 모드

두 가지 실행 모드가 있습니다.

* 수동: 테스트 시 워크플로우를 수동으로 실행합니다. 수동 실행을 시작하려면 **워크플로우 테스트**를 선택합니다. 활성 워크플로우의 수동 실행을 수행할 수 있지만 n8n은 개발 및 테스트 중에 워크플로우를 **비활성**으로 설정하는 것을 권장합니다.
* 프로덕션: 프로덕션 워크플로우는 자동으로 실행되는 워크플로우입니다. 이를 활성화하려면 워크플로우를 **활성**으로 설정합니다.


## 실행 목록

n8n은 두 가지 실행 목록을 제공합니다.

* [워크플로우 수준 실행](/workflows/executions/single-workflow-executions.md): 이 실행 목록은 단일 워크플로우에 대한 실행을 보여줍니다.
* [모든 실행](/workflows/executions/all-executions.md): 이 목록은 모든 워크플로우에 대한 모든 실행을 보여줍니다.

n8n은 [실행에 사용자 지정 데이터 추가](/workflows/executions/custom-executions-data.md)를 지원합니다.
