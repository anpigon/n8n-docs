# 모든 실행

n8n 인스턴스에서 **모든 실행**을 보려면 **개요** 페이지로 이동한 다음 실행 탭을 클릭합니다. 그러면 액세스 권한이 있는 워크플로우의 모든 실행이 표시됩니다.

n8n 인스턴스가 **프로젝트**를 지원하는 경우 액세스 권한이 있는 프로젝트 내에서 실행 탭을 볼 수도 있습니다. 그러면 지정된 프로젝트 내의 워크플로우에서만 실행이 표시됩니다.

/// note | 삭제된 워크플로우
워크플로우를 삭제하면 실행 기록도 삭제됩니다. 즉, 삭제된 워크플로우에 대한 실행을 볼 수 없습니다.
///

## 실행 필터링

실행 목록을 필터링할 수 있습니다.

1. **개요** 페이지 또는 특정 **프로젝트** 내에서 **실행** 탭을 선택하여 목록을 엽니다.
2. **필터**를 선택합니다.
3. 필터를 입력합니다. 다음으로 필터링할 수 있습니다.
	* **워크플로우**: 모든 워크플로우 또는 특정 워크플로우 이름을 선택합니다.
	* **상태**: **실패**, **실행 중**, **성공** 또는 **대기 중**에서 선택합니다.
	* **실행 시작**: 지정된 시간에 시작된 실행을 봅니다.
	* **저장된 사용자 지정 데이터**: 코드 노드를 사용하여 워크플로우 내에서 생성하는 데이터입니다. 필터링할 키와 값을 입력합니다. 사용자 지정 데이터 추가에 대한 정보는 [사용자 지정 실행 데이터](/workflows/executions/custom-executions-data.md)를 참조하십시오.

## 실패한 워크플로우 재시도

워크플로우 실행이 실패하면 실행을 다시 시도할 수 있습니다. 실패한 워크플로우를 다시 시도하려면:

1. **개요** 페이지 또는 특정 **프로젝트** 내에서 **실행** 탭을 선택하여 목록을 엽니다.
2. 다시 시도하려는 실행에서 **실행 재시도** <span class="inline-image">![옵션 메뉴 아이콘](/_images/common-icons/three-dot-options-menu.png){.off-glb}</span>를 선택합니다.
--8<-- "_snippets/workflows/executions/retry-options.md"

## 이전 실행의 데이터를 현재 워크플로우로 로드

이전 워크플로우의 데이터를 캔버스로 다시 로드할 수 있습니다. 자세한 내용은 [실행 디버그](/workflows/executions/debug.md)를 참조하십시오.
