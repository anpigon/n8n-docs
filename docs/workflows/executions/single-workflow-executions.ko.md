# 워크플로우 수준 실행 목록

워크플로우의 **실행** 목록은 해당 워크플로우에 대한 모든 실행을 보여줍니다.

/// note | 삭제된 워크플로우
워크플로우를 삭제하면 실행 기록도 삭제됩니다. 즉, 삭제된 워크플로우에 대한 실행을 볼 수 없습니다.
///

/// note | 실행 기록 및 워크플로우 기록
실행 목록을 [워크플로우 기록](/workflows/history.md)과 혼동하지 마십시오.

실행은 워크플로우 실행입니다. 실행 목록을 사용하면 현재 버전의 워크플로우의 이전 실행을 볼 수 있습니다. 이전 실행을 편집기로 복사하여 현재 워크플로우에서 [과거 실행 디버그 및 다시 실행](/workflows/executions/debug.md)할 수 있습니다.

워크플로우 기록은 워크플로우의 이전 버전입니다. 예를 들어 다른 노드가 있거나 다른 매개변수가 설정된 버전입니다.
///


## 단일 워크플로우에 대한 실행 보기

워크플로우에서 상단 메뉴의 **실행** 탭을 선택합니다. 해당 워크플로우의 모든 실행을 미리 볼 수 있습니다.

## 실행 필터링

실행 목록을 필터링할 수 있습니다.

1. 워크플로우에서 **실행**을 선택합니다.
2. **필터**를 선택합니다.
3. 필터를 입력합니다. 다음으로 필터링할 수 있습니다.
	* **상태**: **실패**, **실행 중**, **성공** 또는 **대기 중**에서 선택합니다.
	* **실행 시작**: 지정된 시간에 시작된 실행을 봅니다.
	* **저장된 사용자 지정 데이터**: 코드 노드를 사용하여 워크플로우 내에서 생성하는 데이터입니다. 필터링할 키와 값을 입력합니다. 사용자 지정 데이터 추가에 대한 정보는 [사용자 지정 실행 데이터](/workflows/executions/custom-executions-data.md)를 참조하십시오.

## 실패한 워크플로우 재시도

워크플로우 실행이 실패하면 실행을 다시 시도할 수 있습니다. 실패한 워크플로우를 다시 시도하려면:

1. **실행** 목록을 엽니다.
2. 다시 시도하려는 워크플로우 실행에 대해 **새로 고침** <span class="inline-image">![새로 고침 아이콘](/_images/common-icons/refresh.png){.off-glb}</span>을 선택합니다.
