# 워크플로우 생성

[워크플로우](/glossary.md#workflow-n8n)는 프로세스를 자동화하기 위해 함께 연결된 노드의 모음입니다. [워크플로우 캔버스](/glossary.md#canvas-n8n)에서 워크플로우를 빌드합니다.

## 워크플로우 생성

1. 사이드 메뉴의 왼쪽 상단 모서리에 있는 <span class="inline-image">![범용 리소스 생성 아이콘](/_images/common-icons/universal-resource-button.png){.off-glb}</span> **버튼**을 선택합니다. 워크플로우를 선택합니다.
2. n8n 인스턴스가 프로젝트를 지원하는 경우 **개인 공간** 또는 액세스 권한이 있는 특정 **프로젝트** 내에서 워크플로우를 생성할지 여부도 선택해야 합니다. 커뮤니티 버전을 사용하는 경우 항상 개인 공간 내에서 워크플로우를 생성합니다.
3. 트리거 노드를 추가하여 시작합니다. **첫 번째 단계 추가...**를 선택합니다.

또는:

1. **개요** 페이지 또는 특정 **프로젝트**의 오른쪽 상단 모서리에 있는 <span class="inline-image">![범용 리소스 생성 아이콘](/_images/common-icons/universal-resource-button.png){.off-glb}</span> **생성** 버튼을 선택합니다. 워크플로우를 선택합니다.
2. **개요** 페이지에서 이 작업을 수행하는 경우 개인 공간 내에서 워크플로우를 생성합니다. 프로젝트 내에서 이 작업을 수행하는 경우 해당 특정 프로젝트 내에서 워크플로우를 생성합니다.
3. 트리거 노드를 추가하여 시작합니다. **첫 번째 단계 추가...**를 선택합니다.

워크플로우를 처음 빌드하는 경우 [빠른 시작 가이드](/try-it-out/index.md)를 사용하여 n8n 기능을 빠르게 사용해 볼 수 있습니다.

## 수동으로 워크플로우 실행

빌드 및 테스트 중이거나 워크플로우에 트리거 노드가 없는 경우 워크플로우를 수동으로 실행해야 할 수 있습니다.

수동으로 실행하려면 **워크플로우 테스트**를 선택합니다.

## 자동으로 워크플로우 실행

모든 새 워크플로우는 기본적으로 비활성 상태입니다.

트리거 노드 또는 웹훅 노드로 시작하는 워크플로우를 활성화하여 자동으로 실행되도록 해야 합니다. 워크플로우가 비활성 상태이면 수동으로 실행해야 합니다.

워크플로우를 활성화하거나 비활성화하려면 워크플로우를 열고 **비활성** / **활성**을 토글합니다.

워크플로우가 활성화되면 트리거 조건이 충족될 때마다 실행됩니다.
