# 워크플로우

[워크플로우](/glossary.md#workflow-n8n)는 프로세스를 자동화하기 위해 함께 연결된 노드의 모음입니다.


* 워크플로우 [생성](/workflows/create.md).
* 시작하는 데 도움이 되는 [워크플로우 템플릿](/workflows/templates.md)을 사용합니다.
* n8n의 자동화의 주요 [구성 요소](/workflows/components/index.md)에 대해 알아봅니다.
* [실행](/workflows/executions/index.md) 목록을 사용하여 디버그합니다.
* 사용자 간에 워크플로우 [공유](/workflows/sharing.md).

워크플로우를 처음 빌드하는 경우 [빠른 시작 가이드](/try-it-out/index.md)를 사용하여 n8n 기능을 빠르게 사용해 볼 수 있습니다.
