# 워크플로우 설정

워크플로우 설정을 사용하여 개별 워크플로우에 대한 워크플로우 동작을 사용자 지정할 수 있습니다.

설정을 열려면:

1. 워크플로우를 엽니다.
2. **옵션** <span class="inline-image">![옵션 메뉴](/_images/common-icons/three-dot-options-menu.png){.off-glb}</span> 메뉴를 선택합니다.
3. **설정**을 선택합니다. n8n이 **워크플로우 설정** 모달을 엽니다.


다음 설정을 사용할 수 있습니다.

* **실행 순서**: 다중 분기 워크플로우의 실행 순서를 선택합니다. **v0(레거시)**는 각 분기의 첫 번째 노드를 실행한 다음 각 분기의 두 번째 노드를 실행하는 식으로 진행합니다. **v1(권장)**은 각 분기를 차례로 실행하여 한 분기를 완료한 후 다른 분기를 시작합니다. n8n은 [캔버스](/glossary.md#canvas-n8n)에서의 위치에 따라 위에서 아래로 분기 순서를 정합니다. 두 분기가 같은 높이에 있으면 가장 왼쪽에 있는 분기가 먼저 실행됩니다.
* **오류 워크플로우**: 현재 워크플로우가 실패할 경우 트리거할 워크플로우를 선택합니다. 자세한 내용은 [오류 워크플로우](/flow-logic/error-handling.md)를 참조하십시오.
* **이 워크플로우는 다음에서 호출할 수 있습니다**: 다른 워크플로우가 이 워크플로우를 호출할 수 있는지 여부를 선택합니다.
* **시간대**: 워크플로우에서 사용할 시간대를 설정합니다. 기본 시간대는 EDT(뉴욕)입니다. 시간대 설정은 스케줄 트리거 노드에 중요합니다.
* **실패한 프로덕션 실행 저장**: n8n이 활성 워크플로우에 대해 실패한 실행을 저장해야 하는지 여부입니다.
* **성공적인 프로덕션 실행 저장**: n8n이 활성 워크플로우에 대해 성공적인 실행을 저장해야 하는지 여부입니다.
* **수동 실행 저장**: n8n이 편집기에서 사용자가 시작한 워크플로우에 대한 실행을 저장해야 하는지 여부입니다.
* **실행 진행률 저장**: n8n이 각 노드에 대한 실행 데이터를 저장해야 하는지 여부입니다. **저장**으로 설정하면 오류 발생 시 워크플로우가 중지된 위치에서 다시 시작됩니다. 이로 인해 대기 시간이 늘어날 수 있습니다.
* **시간 초과 워크플로우**: n8n이 현재 워크플로우 실행을 취소해야 하는 기간을 설정하도록 설정/해제합니다.
	* **시간 초과 후**: 워크플로우가 시간 초과되어야 하는 시간을 시, 분, 초 단위로 설정합니다. n8n 클라우드 사용자의 경우 n8n은 각 플랜에 대해 사용 가능한 최대 시간 초과를 적용합니다.
