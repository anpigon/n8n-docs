# 워크플로우 템플릿

새 워크플로우를 만들 때 빈 워크플로우로 시작할지 또는 기존 [템플릿](/glossary.md#template-n8n)을 사용할지 선택할 수 있습니다.

템플릿은 다음을 제공합니다.

* 시작하는 데 도움이 됩니다. n8n에는 이미 필요한 작업을 수행하는 템플릿이 있을 수 있습니다.
* 빌드할 수 있는 항목의 예
* 자신만의 워크플로우를 만들기 위한 모범 사례

## 템플릿 액세스

<span class="inline-image">![템플릿 보기 아이콘](/_images/common-icons/templates.png){.off-glb}</span> **템플릿**을 선택하여 템플릿 라이브러리를 봅니다.

n8n의 템플릿 라이브러리를 사용하는 경우 [n8n 웹사이트의 워크플로우](https://n8n.io/workflows/){:target=_blank .external-link}를 탐색하게 됩니다. 조직에서 제공하는 사용자 지정 라이브러리를 사용하는 경우 앱 내에서 템플릿을 검색하고 탐색할 수 있습니다.
