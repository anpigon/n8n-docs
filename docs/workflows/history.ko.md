# 워크플로우 기록

/// info | 기능 가용성
* 전체 워크플로우 기록은 엔터프라이즈 클라우드 및 엔터프라이즈 자체 호스팅에서 사용할 수 있습니다.
* 지난 5일간의 버전은 클라우드 프로 사용자가 사용할 수 있습니다.
* 지난 24시간 동안의 버전은 등록된 커뮤니티 사용자가 사용할 수 있습니다.
///	

워크플로우 기록을 사용하여 워크플로우의 이전 버전을 보고 복원합니다.

## 워크플로우 기록 이해

n8n은 다음과 같은 경우 새 버전을 만듭니다.

 * 워크플로우를 저장합니다.
 * 이전 버전을 복원합니다. n8n은 복원하기 전에 최신 버전을 저장합니다.
 * [소스 제어](/source-control-environments/index.md)를 사용하여 Git 리포지토리에서 가져옵니다. n8n은 버전을 Git이 아닌 인스턴스 데이터베이스에 저장합니다.

/// note | 워크플로우 기록 및 실행 기록
워크플로우 기록을 [워크플로우 수준 실행 목록](/workflows/executions/single-workflow-executions.md)과 혼동하지 마십시오.

실행은 워크플로우 실행입니다. 실행 목록을 사용하면 현재 버전의 워크플로우의 이전 실행을 볼 수 있습니다. 이전 실행을 편집기로 복사하여 현재 워크플로우에서 [과거 실행 디버그 및 다시 실행](/workflows/executions/debug.md)할 수 있습니다.

워크플로우 기록은 워크플로우의 이전 버전입니다. 예를 들어 다른 노드가 있거나 다른 매개변수가 설정된 버전입니다.
///


## 워크플로우 기록 보기

워크플로우 기록을 보려면:

1. 워크플로우를 엽니다.
2. **워크플로우 기록** <span class="inline-image">![워크플로우 기록 아이콘](/_images/common-icons/workflow-history.png){.off-glb}</span>을 선택합니다. n8n이 저장된 워크플로우 버전과 선택한 버전의 미리보기가 있는 캔버스를 보여주는 메뉴를 엽니다.

## 이전 버전 복원 또는 복사

이전 워크플로우 버전을 복원하거나 복사할 수 있습니다.

1. 복원하거나 복사하려는 버전에서 **옵션** <span class="inline-image">![옵션 아이콘](/_images/common-icons/three-dot-options-menu.png){.off-glb}</span>을 선택합니다.
2. 수행할 작업을 선택합니다.
	* **이 버전 복원**: 현재 워크플로우를 선택한 버전으로 바꿉니다.
	* **새 워크플로우로 복제**: 선택한 버전을 기반으로 새 워크플로우를 만듭니다.
	* **새 탭에서 버전 열기**: 선택한 버전을 표시하는 두 번째 탭을 엽니다. 이를 사용하여 버전을 비교합니다.
	* **다운로드**: 버전을 JSON으로 다운로드합니다.
