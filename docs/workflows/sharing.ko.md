# 워크플로우 공유

/// info | 기능 가용성
프로 및 엔터프라이즈 클라우드 플랜 및 엔터프라이즈 자체 호스팅 플랜에서 사용 가능합니다.
///

워크플로우 공유를 사용하면 동일한 n8n 인스턴스의 사용자 간에 워크플로우를 공유할 수 있습니다.

사용자는 자신이 만든 워크플로우를 공유할 수 있습니다. 인스턴스 소유자 및 관리자 역할이 있는 사용자는 인스턴스의 모든 워크플로우를 보고 공유할 수 있습니다. 소유자 및 관리자에 대한 자세한 내용은 [계정 유형](/user-management/account-types.md)을 참조하십시오.

## 워크플로우 공유

1. 공유하려는 워크플로우를 엽니다.
2. **공유**를 선택합니다.
3. **사용자 추가**에서 공유하려는 사용자를 찾아 선택합니다.
4. **저장**을 선택합니다.

## 공유 워크플로우 보기

**워크플로우** 목록에서 워크플로우를 찾아보고 검색할 수 있습니다. 목록의 워크플로우는 프로젝트에 따라 다릅니다.

* **개요**는 액세스할 수 있는 모든 워크플로우를 나열합니다. 여기에는 다음이 포함됩니다.
	* 자신의 워크플로우.
	* 자신과 공유된 워크플로우.
	* 자신이 구성원인 프로젝트의 워크플로우.
	* 인스턴스 소유자 또는 관리자로 로그인한 경우: 인스턴스의 모든 워크플로우.
* 기타 프로젝트: 프로젝트의 모든 워크플로우.

## 워크플로우 역할 및 권한

워크플로우 역할에는 생성자와 편집자의 두 가지가 있습니다. 생성자는 워크플로우를 만든 사용자입니다. 편집자는 워크플로우에 액세스할 수 있는 다른 사용자입니다.

사용자를 삭제하는 경우를 제외하고는 워크플로우 소유자를 변경할 수 없습니다.

/// note | 자격 증명
워크플로우 공유를 통해 편집자는 워크플로우에서 사용되는 모든 [자격 증명](/glossary.md#credential-n8n)을 사용할 수 있습니다. 여기에는 [자격 증명 공유](/credentials/credential-sharing.md)를 사용하여 명시적으로 공유되지 않은 자격 증명도 포함됩니다.
///
### 권한

| 권한 | 생성자 | 편집자 | 
| ----------- | ------- | ------ | 
| 워크플로우 보기(읽기 전용) | :white_check_mark: | :white_check_mark: |
| 실행 보기 | :white_check_mark: | :white_check_mark: |
| 업데이트(태그 포함) | :white_check_mark: | :white_check_mark: |
| 실행 | :white_check_mark: | :white_check_mark: |
| 공유 | :white_check_mark: | :x: |
| 내보내기 | :white_check_mark: | :white_check_mark: |
| 삭제 | :white_check_mark: | :x: |

## 공유되지 않은 자격 증명을 사용한 노드 편집 제한

n8n의 공유는 최소 권한 원칙에 따라 작동합니다. 즉, 사용자가 워크플로우를 공유했지만 자격 증명을 공유하지 않은 경우 해당 자격 증명을 사용하는 워크플로우 내의 노드를 편집할 수 없습니다. 워크플로우를 보고 실행하고 공유되지 않은 자격 증명을 사용하지 않는 노드를 편집할 수 있습니다.

자격 증명 공유에 대한 지침은 [자격 증명 공유](/credentials/credential-sharing.md)를 참조하십시오.
