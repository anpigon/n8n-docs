# 노드

[노드](/glossary.md#node-n8n)는 [워크플로우](/glossary.md#workflow-n8n)의 핵심 구성 요소입니다. 다음과 같은 다양한 작업을 수행합니다.

* 워크플로우 시작.
* 데이터 가져오기 및 보내기.
* 데이터 처리 및 조작.

n8n은 내장 노드 모음을 제공하며 자신만의 노드를 만들 수도 있습니다. 다음을 참조하십시오.

* [내장 통합](/integrations/builtin/node-types.md)에서 노드 라이브러리를 찾아보십시오.
* [커뮤니티 노드](/integrations/community-nodes/installation/index.md)에서 커뮤니티에서 만든 노드를 찾고 설치하는 방법에 대한 지침을 확인하십시오.
* [노드 만들기](/integrations/creating-nodes/overview.md)에서 자신만의 노드 만들기를 시작하십시오.


## 워크플로우에 노드 추가

### 빈 워크플로우에 노드 추가

1. **첫 단계 추가**를 선택합니다. n8n이 노드 패널을 열고 [트리거 노드](/glossary.md#trigger-node-n8n)를 검색하거나 찾아볼 수 있습니다.
2. 사용하려는 트리거를 선택합니다.

    /// note | 올바른 앱 이벤트 선택
	**앱 이벤트 시**를 선택하면 n8n이 지원되는 모든 서비스 목록을 표시합니다. 이 목록을 사용하여 n8n의 통합을 찾아보고 선택한 서비스의 이벤트에 대한 응답으로 워크플로우를 트리거합니다. 모든 통합에 트리거가 있는 것은 아닙니다. 트리거로 사용할 수 있는 항목을 보려면 노드를 선택하십시오. 트리거를 사용할 수 있는 경우 사용 가능한 작업 목록 상단에 표시됩니다.

## 노드 컨트롤

노드 컨트롤을 보려면 캔버스에서 노드 위로 마우스를 가져갑니다.

* **단계 실행** <span class="inline-image">![단계 실행 아이콘](/_images/common-icons/play-node.png){.off-glb}</span>: 노드를 실행합니다.
* **비활성화** <span class="inline-image">![노드 비활성화 아이콘](/_images/common-icons/power-off.png){.off-glb}</span>: 노드를 비활성화합니다.
* **삭제** <span class="inline-image">![노드 삭제 아이콘](/_images/common-icons/delete-node.png){.off-glb}</span>: 노드를 삭제합니다.
* **노드 컨텍스트 메뉴** <span class="inline-image">![노드 컨텍스트 메뉴 아이콘](/_images/common-icons/node-context-menu.png){.off-glb}</span>: 노드 작업을 선택합니다. 사용 가능한 작업:
	* 노드 열기
	* 단계 실행
	* 노드 이름 바꾸기
	* 노드 비활성화
	* 노드 고정
	* 노드 복사
	* 노드 복제
	* 모두 선택
	* 선택 취소
	* 노드 삭제

## 노드 설정

**설정** 탭 아래의 노드 설정을 사용하면 노드 동작을 제어하고 노드 메모를 추가할 수 있습니다.

활성화되거나 설정되면 다음을 수행합니다.

* **요청 옵션**: **옵션 추가**를 선택하여 이러한 옵션을 보고 선택합니다.
	- **일괄 처리**: 많은 수의 입력 항목을 일괄 처리하는 방법을 제어합니다.
	- **SSL 문제 무시**: SSL 유효성 검사가 불가능한 경우에도 응답을 다운로드합니다.
	- **프록시**: HTTP 프록시를 지정해야 하는 경우 이 옵션을 사용합니다.
	- **시간 초과**: 요청에 대한 시간 초과를 ms 단위로 설정합니다.
* **항상 데이터 출력**: 노드가 실행 중에 데이터를 반환하지 않더라도 노드는 빈 항목을 반환합니다. IF 노드에서 이 설정을 사용하면 무한 루프가 발생할 수 있으므로 주의하십시오.
* **한 번 실행**: 노드는 수신하는 첫 번째 항목의 데이터로 한 번 실행됩니다. 추가 항목은 처리하지 않습니다.
* **실패 시 재시도**: 실행이 실패하면 노드가 성공할 때까지 다시 실행됩니다.
* **오류 발생 시**:
    - **워크플로우 중지**: 오류가 발생하면 전체 워크플로우를 중지하여 추가 노드 실행을 방지합니다.
    - **계속**: 오류에도 불구하고 다음 노드로 진행하여 마지막 유효한 데이터를 사용합니다.
    - **계속(오류 출력 사용)**: 워크플로우 실행을 계속하여 잠재적인 처리를 위해 오류 정보를 다음 노드로 전달합니다.

노드 메모를 사용하여 워크플로우를 문서화할 수 있습니다.

* **메모**: 노드와 함께 저장할 메모입니다.
* **흐름에 메모 표시**: 활성화되면 n8n이 워크플로우에 메모를 부제로 표시합니다.
