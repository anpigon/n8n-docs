# 연결

연결은 워크플로우를 통해 데이터를 라우팅하기 위해 노드 간의 링크를 설정합니다. 두 노드 간의 연결은 한 노드의 출력에서 다른 노드의 입력으로 데이터를 전달합니다.

![연결 생성 및 삭제 예시](/_images/workflows/components/connections/example.gif)

## 연결 생성

두 노드 간에 연결을 생성하려면 노드의 오른쪽에 있는 회색 점 또는 **노드 추가** <span class="inline-image">![노드 추가 아이콘](/_images/try-it-out/add-node-small.png){.off-glb}</span>를 선택하고 화살표를 다음 노드의 왼쪽에 있는 회색 사각형으로 밉니다.

## 연결 삭제

연결 위로 마우스를 가져간 다음 **삭제** <span class="inline-image">![커넥터 삭제 아이콘](/_images/common-icons/delete-connector.png){.off-glb}</span>를 선택합니다.
