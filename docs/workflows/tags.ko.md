# 태그

워크플로우 태그를 사용하면 워크플로우에 레이블을 지정할 수 있습니다. 그런 다음 태그별로 워크플로우를 필터링할 수 있습니다.

태그는 전역적입니다. 즉, 태그를 만들면 n8n 인스턴스의 모든 사용자가 사용할 수 있습니다.

## 워크플로우에 태그 추가

워크플로우에 태그를 추가하려면:

1. 워크플로우에서 **+ 태그 추가**를 선택합니다.
2. 기존 태그를 선택하거나 새 태그 이름을 입력합니다.
3. 태그를 선택하고 태그 모달에서 벗어나면 n8n이 워크플로우 이름 옆에 태그를 표시합니다.

둘 이상의 태그를 추가할 수 있습니다.

## 태그로 필터링

인스턴스에서 워크플로우를 탐색할 때 태그로 필터링할 수 있습니다.

1. **워크플로우** 페이지에서 **필터**를 선택합니다.
2. **태그**를 선택합니다.
3. 필터링하려는 태그를 선택합니다. n8n이 해당 태그가 있는 워크플로우를 나열합니다.

## 태그 관리

기존 태그를 편집할 수 있습니다. 인스턴스 소유자는 태그를 삭제할 수 있습니다.

1. **태그 관리**를 선택합니다. 이 옵션은 **워크플로우** 페이지의 **필터** > **태그** 또는 워크플로우의 **+ 태그 추가** 모달에서 사용할 수 있습니다.
2. 변경하려는 태그 위로 마우스를 가져갑니다.
3. 이름을 바꾸려면 **편집** <span class="inline-image">![노드 추가 아이콘](/_images/common-icons/edit.png){.off-glb}</span>을 선택하고 삭제하려면 **삭제** <span class="inline-image">![노드 추가 아이콘](/_images/common-icons/delete.png){.off-glb}</span>를 선택합니다.
