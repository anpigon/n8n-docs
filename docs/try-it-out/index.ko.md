# 직접 해보기

n8n을 배우는 가장 좋은 방법은 튜토리얼을 사용하여 사용자 인터페이스와 사용 가능한 다양한 유형의 노드 및 통합에 익숙해지는 것입니다. 시작하는 데 도움이 되는 자료는 다음과 같습니다.

- 빠른 소개를 찾고 계신가요? ["첫 번째 워크플로우" 튜토리얼](/try-it-out/tutorial-first-workflow.md)을 확인하세요.
- AI로 무엇을 할 수 있는지 궁금하신가요? [n8n으로 AI 채팅 에이전트를 구축하는 방법](/advanced-ai/intro-tutorial.md)을 알아보세요.
- 광범위한 예제를 통해 작업하는 것을 선호하시나요? 아마도 [코스](/courses/index.md)가 당신에게 적합할 것입니다.
