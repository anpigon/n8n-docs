# 다중 분기 워크플로우의 실행 순서

n8n의 노드 실행 순서는 사용 중인 n8n 버전에 따라 다릅니다.

* 버전 1.0 이전에 생성된 워크플로우의 경우: n8n은 각 분기의 첫 번째 노드를 실행한 다음 각 분기의 두 번째 노드를 실행하는 식으로 진행합니다.
* 버전 1.0 이상에서 생성된 워크플로우의 경우: 각 분기를 차례로 실행하여 한 분기를 완료한 후 다른 분기를 시작합니다. n8n은 [캔버스](/glossary.md#canvas-n8n)에서의 위치에 따라 위에서 아래로 분기 순서를 정합니다. 두 분기가 같은 높이에 있으면 가장 왼쪽에 있는 분기가 먼저 실행됩니다.

[워크플로우 설정](/workflows/settings.md)에서 실행 순서를 변경할 수 있습니다.
