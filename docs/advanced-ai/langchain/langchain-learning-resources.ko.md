# LangChain 학습 리소스

n8n을 사용하기 위해 LangChain에 대한 자세한 내용을 알 필요는 없지만 몇 가지 개념을 배우는 것이 도움이 될 수 있습니다. 이 페이지에는 n8n 사람들이 유용하다고 생각한 학습 리소스 목록이 있습니다.

[LangChain 설명서](https://docs.langchain.com/docs/){:target=_blank .external-link}에는 주요 개념과 가능한 사용 사례에 대한 소개가 포함되어 있습니다. 빠른 시작, 코드 예제 및 API 설명서를 보려면 [LangChain | Python](https://python.langchain.com/docs/get_started/introduction){:target=_blank .external-link} 또는 [LangChain | JavaScript](https://js.langchain.com/docs/get_started/introduction/){:target=_blank .external-link} 설명서를 선택하세요. LangChain은 또한 잠재적인 사용 사례와 일반적인 패턴에 대한 아이디어를 제공하는 [코드 템플릿](https://github.com/langchain-ai/langchain/tree/master/cookbook){:target=_blank .external-link}(Python만 해당)을 제공합니다.

[제품 담당자가 LangChain에 대해 알아야 할 사항](https://www.commandbar.com/blog/langchain-guide){:target=_blank .external-link}은 유용한 비유로 설명된 용어 및 개념 목록을 제공합니다. 폭넓은 청중을 대상으로 합니다.

비디오를 선호하는 경우 Greg Kamradt의 이 [YouTube 시리즈](https://youtu.be/_v_fgW2SkkQ?si=8Z2tfAoXnN3lXU9s){:target=_blank .external-link}는 LangChain 설명서를 통해 작업하며 코드 예제를 제공합니다.

n8n은 [Discord](https://discord.gg/bAt54txhHg){:target=_blank .external-link}에서 LangChain에 대해 논의할 수 있는 공간을 제공합니다. 참여하여 프로젝트를 공유하고 커뮤니티와 아이디어를 논의하세요.
